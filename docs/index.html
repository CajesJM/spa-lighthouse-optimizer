THE METHOD

From a score to
a sound decision.

A perfect number is not the workflow. Evidence is. The skill helps your agent find what failed, trace the cause, make the smallest useful change, and measure again.

01 / BASELINE↗

Measure the real site.

Audit a production build or deployed URL across representative routes, mobile and desktop. Repeat runs reveal noisy results.

JSON reports → median summary
02 / DIAGNOSE⌕

Find the actual cause.

Inspect scored failures, console errors, affected resources, and elements. Separate project fixes from hosting and third-party limits.

Audit evidence → focused changes
03 / VERIFY✓

Protect what works.

Rebuild and check behavior, keyboard access, and responsive views. Compare reports with the same URL and Lighthouse settings.

Before / after → honest results
